| Audit | Checked | Findings | Action |
|---|---|---|---|
| Reliability | Every external dependency has a fallback and an honest on-screen sentence | Board: TV shows "cannot reach Vita Heart" with the status. | Security | Secrets, auth, input handling | No secrets in git (scan of tracked files for key patterns clean; Ring key and AgentCore config are local files, Lambda env only). Pydantic bounds on every input. | documented CORS choice in README |
| Honesty | Nothing synthetic shown as live; no health claims | Heart rate labelled live / recorded / test signal; replay refuses to join a differently labelled session.
